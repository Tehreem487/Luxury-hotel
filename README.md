# AURELIA — Luxury Restaurant Website

A premium restaurant website concept based on the supplied visual reference:
- black / charcoal luxury palette
- warm champagne-gold typography
- cinematic food photography
- editorial serif typography
- fixed transparent luxury navigation
- award strip
- restaurant story
- filterable menu
- cinematic experience section
- private dining section
- reservation modal
- responsive mobile navigation
- scroll reveal and parallax effects

## Replace with real client assets
The demo uses remote Unsplash images. For a real client site, replace them with licensed restaurant photography.

For the cinematic video modal, add:
assets/restaurant-story.mp4

Then replace the video placeholder in index.html with a <video> element.

## Run
Open `index.html` in a browser or use VS Code Live Server.
